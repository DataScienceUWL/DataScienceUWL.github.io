Explore Tools

Interactive tools for exploring and summarizing data.

  • Descriptive Statistics

    Summary statistics, histograms, dotplots, and boxplots for a single numeric variable.

  • Two-Variable / Regression

    Scatterplot with regression line, correlation, R-squared, and residual plot for two numeric variables.

  • Categorical Data

    Contingency table with proportion toggles and bar chart (frequency, stacked, 100% stacked).
