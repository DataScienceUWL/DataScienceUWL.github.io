1. (12 pts) If \(yz + x \ln y = z^2\) find \(\partial z / \partial y\).

Solution:

Use implicit differentiation with respect to \(y\), treating \(z\) as a function of \(x\) and \(y\):

\[\frac{\partial}{\partial y}(yz) + \frac{\partial}{\partial y}(x \ln y) = \frac{\partial}{\partial y}(z^2)\] \[y\frac{\partial z}{\partial y} + z \cdot 1 + \frac{x}{y} = 2z\frac{\partial z}{\partial y}\]

Collect terms with \(\frac{\partial z}{\partial y}\):

\[y\frac{\partial z}{\partial y} - 2z\frac{\partial z}{\partial y} = -z - \frac{x}{y}\] \[(y - 2z)\frac{\partial z}{\partial y} = -z - \frac{x}{y}\]

Answer:

\[\frac{\partial z}{\partial y} = \frac{-z - \frac{x}{y}}{y - 2z} = \frac{-zy - x}{y(y - 2z)} = \frac{yz + x}{2yz - y^2}\]
2. (20 pts) Consider the function \(f(x, y) = 64 - 5x^2 - 4y^2\)

(a) (10 pts) At the point \((x, y) = (2, 3)\) use linearization or differentials to estimate the value of \(f(2.1, 2.9)\).

Solution:

Find partial derivatives:

\[f_x(x,y) = -10x \quad \Rightarrow \quad f_x(2,3) = -10(2) = -20\] \[f_y(x,y) = -8y \quad \Rightarrow \quad f_y(2,3) = -8(3) = -24\]

Find \(f(2,3)\):

\[f(2,3) = 64 - 5(2)^2 - 4(3)^2 = 64 - 20 - 36 = 8\]

The linearization is:

\[L(x,y) = f(2,3) + f_x(2,3)(x-2) + f_y(2,3)(y-3)\] \[L(x,y) = 8 - 20(x-2) - 24(y-3)\]

Estimate \(f(2.1, 2.9)\):

\[f(2.1, 2.9) \approx 8 - 20(2.1-2) - 24(2.9-3)\] \[= 8 - 20(0.1) - 24(-0.1) = 8 - 2 + 2.4 = 8.4\]

Answer: \(f(2.1, 2.9) \approx 8.4\)

(b) (10 pts) From the point \((2, 3)\) in which directions should you move so that the rate of change is 0?

Solution:

The gradient at \((2,3)\) is:

\[\nabla f(2,3) = \langle -20, -24 \rangle\]

The rate of change is 0 when moving perpendicular to the gradient.

Answer: Move in directions \(\vec{d} = \langle -24, 20 \rangle\) or \(\vec{d} = \langle 24, -20 \rangle\)

(Any scalar multiple of these vectors is also correct.)

3. (16 pts) Consider the surface \(x + y + z = e^{xyz}\):

(a) (8 pts) Find the equation of the tangent plane at the point \((0, 0, 1)\).

Solution:

Write as \(F(x,y,z) = x + y + z - e^{xyz} = 0\)

Find the gradient:

\[\nabla F = \langle 1 - e^{xyz} \cdot yz, \; 1 - e^{xyz} \cdot xz, \; 1 - e^{xyz} \cdot xy \rangle\]

At \((0, 0, 1)\):

\[\nabla F(0,0,1) = \langle 1 - e^0 \cdot 0, \; 1 - e^0 \cdot 0, \; 1 - e^0 \cdot 0 \rangle = \langle 1, 1, 1 \rangle = \vec{n}\]

Tangent plane equation:

\[\vec{n} \cdot \langle x, y, z \rangle = \vec{n} \cdot \langle 0, 0, 1 \rangle\] \[1(x) + 1(y) + 1(z) = 1\]

Answer: \(x + y + z = 1\)

(b) (8 pts) Find the equation of the normal line to the surface at the point \((0, 0, 1)\).

Solution:

The normal line passes through \((0, 0, 1)\) with direction \(\vec{n} = \langle 1, 1, 1 \rangle\):

\[\vec{r}(t) = \vec{r}_0 + t\vec{n} = \langle 0, 0, 1 \rangle + t\langle 1, 1, 1 \rangle\]

Answer: \(\vec{r}(t) = \langle t, t, 1+t \rangle\)

Or in symmetric form: \(x = y = z - 1\)

4. (12 pts) Find and classify all critical points of \(f(x, y) = x^5y + 10x^4 - 32y\).

Solution:

Find partial derivatives and set equal to zero:

\[f_x = 5x^4y + 40x^3 = 5x^3(xy + 8) = 0\] \[f_y = x^5 - 32 = 0 \quad \Rightarrow \quad x^5 = 32 \quad \Rightarrow \quad x = 2\]

If \(x = 2\): From \(f_x = 0\): \(5(2)^3(2y + 8) = 0\)

\[2y + 8 = 0 \quad \Rightarrow \quad y = -4\]

Critical point: \((2, -4)\)

Second derivative test:

\[f_{xx} = 20x^3y + 120x^2\] \[f_{yy} = 0\] \[f_{xy} = 5x^4\]

At \((2, -4)\):

\[f_{xx}(2,-4) = 20(8)(-4) + 120(4) = -640 + 480 = -160\] \[f_{yy}(2,-4) = 0\] \[f_{xy}(2,-4) = 5(16) = 80\]

Discriminant:

\[D = f_{xx}f_{yy} - (f_{xy})^2 = (-160)(0) - (80)^2 = -6400 < 0\]

Answer: Critical point \((2, -4)\) is a saddle point.

5. (16 pts) Find the absolute maximum and minimum values of \(f(x, y) = -x^2 - y^2 + 3x - 4y + 2\) on the circle \(x^2 + y^2 = 25\).

Solution:

Use Lagrange multipliers with constraint \(g(x,y) = x^2 + y^2 - 25 = 0\).

\[\nabla f = \langle -2x + 3, -2y - 4 \rangle\] \[\nabla g = \langle 2x, 2y \rangle\]

Set \(\nabla f = \lambda \nabla g\):

\[-2x + 3 = \lambda \cdot 2x \quad \Rightarrow \quad \lambda = \frac{-2x + 3}{2x}\] \[-2y - 4 = \lambda \cdot 2y \quad \Rightarrow \quad \lambda = \frac{-2y - 4}{2y}\]

Set equal:

\[\frac{-2x + 3}{2x} = \frac{-2y - 4}{2y}\] \[(-2x + 3)(2y) = (-2y - 4)(2x)\] \[-4xy + 6y = -4xy - 8x\] \[6y = -8x \quad \Rightarrow \quad y = -\frac{4}{3}x\]

Substitute into constraint:

\[x^2 + \left(-\frac{4}{3}x\right)^2 = 25\] \[x^2 + \frac{16}{9}x^2 = 25\] \[\frac{25}{9}x^2 = 25 \quad \Rightarrow \quad x^2 = 9 \quad \Rightarrow \quad x = \pm 3\]

Find corresponding \(y\) values:

  • If \(x = 3\): \(y = -\frac{4}{3}(3) = -4\)
  • If \(x = -3\): \(y = -\frac{4}{3}(-3) = 4\)

Evaluate \(f\) at each point:

\[f(3, -4) = -(3)^2 - (-4)^2 + 3(3) - 4(-4) + 2 = -9 - 16 + 9 + 16 + 2 = 2\] \[f(-3, 4) = -(-3)^2 - (4)^2 + 3(-3) - 4(4) + 2 = -9 - 16 - 9 - 16 + 2 = -48\]

Answer: Absolute maximum = 2 at \((3, -4)\); Absolute minimum = \(-48\) at \((-3, 4)\)

6. (12 pts) Evaluate \(\displaystyle \int_0^8 \int_{\sqrt[3]{y}}^2 e^{x^4} \, dx \, dy\) by reversing the order of integration.

Solution:

Analyze the region. Original limits: \(x = \sqrt[3]{y}\) to \(x = 2\), and \(y = 0\) to \(y = 8\).

The curve \(x = \sqrt[3]{y}\) is the same as \(y = x^3\).

Reversed limits: \(0 \leq x \leq 2\) and \(0 \leq y \leq x^3\).

\[\int_0^8 \int_{\sqrt[3]{y}}^2 e^{x^4} \, dx \, dy = \int_0^2 \int_0^{x^3} e^{x^4} \, dy \, dx\]

Integrate with respect to \(y\):

\[= \int_0^2 e^{x^4} \cdot y \Big|_0^{x^3} \, dx = \int_0^2 x^3 e^{x^4} \, dx\]

Let \(u = x^4\), so \(du = 4x^3 \, dx\):

\[= \frac{1}{4} \int_0^{16} e^u \, du = \frac{1}{4} e^u \Big|_0^{16} = \frac{1}{4}(e^{16} - e^0)\]

Answer: \(\displaystyle \frac{1}{4}(e^{16} - 1)\)

7. (12 pts) Set up, but do not evaluate, a double integral to find the volume under the surface \(f(x, y) = y^2\) above the triangle in the \(xy\)-plane with vertices \((1, 0)\), \((2, 1)\), and \((1, 4)\).

Solution:

Find equations of the boundary lines:

  • From \((1,0)\) to \((2,1)\): slope = \(\frac{1-0}{2-1} = 1\), so \(y = x - 1\)
  • From \((2,1)\) to \((1,4)\): slope = \(\frac{4-1}{1-2} = -3\), so \(y = -3x + 7\) or \(x = \frac{7-y}{3}\)
  • From \((1,4)\) to \((1,0)\): vertical line \(x = 1\)

Integrating with \(dy \, dx\) order, for \(1 \leq x \leq 2\):

  • Lower bound: \(y = x - 1\)
  • Upper bound: \(y = -3x + 7\)

Answer:

\[V = \int_1^2 \int_{x-1}^{-3x+7} y^2 \, dy \, dx\]
