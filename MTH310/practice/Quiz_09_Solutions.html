Problem 1: Line Integral with Respect to Arc Length

Evaluate \(\displaystyle\int_C yz \cos x \, ds\) where \(C\) is the curve parameterized by \(x = t\), \(y = 3\cos t\), \(z = 3\sin t\) for \(0 \le t \le \pi\).

Solution:

Step 1: Find \(ds\).

\[ds = \sqrt{(x')^2 + (y')^2 + (z')^2} \, dt = \sqrt{1^2 + (-3\sin t)^2 + (3\cos t)^2} \, dt\]

\[= \sqrt{1 + 9\sin^2 t + 9\cos^2 t} \, dt = \sqrt{1 + 9} \, dt = \sqrt{10} \, dt\]

Step 2: Set up the integral.

\[\int_C yz\cos x \, ds = \int_0^\pi (3\cos t)(3\sin t)(\cos t) \cdot \sqrt{10} \, dt\]

\[= 9\sqrt{10} \int_0^\pi \cos^2 t \sin t \, dt\]

Step 3: Use substitution \(u = \cos t\), \(du = -\sin t \, dt\).

When \(t = 0\): \(u = 1\). When \(t = \pi\): \(u = -1\).

\[= 9\sqrt{10} \int_1^{-1} u^2 (-du) = 9\sqrt{10} \int_{-1}^1 u^2 \, du\]

\[= 9\sqrt{10} \cdot \frac{u^3}{3} \Big|_{-1}^1 = 9\sqrt{10} \cdot \frac{1}{3}(1 - (-1)) = 9\sqrt{10} \cdot \frac{2}{3}\]

\[= \boxed{6\sqrt{10}}\]

Problem 2: Line Integral Using Green's Theorem

Evaluate \(\displaystyle\int_C \sqrt{1 + x^3} \, dx + 2xy \, dy\) where \(C\) is the counter-clockwise boundary of the triangle with vertices \((0, 0)\), \((1, 0)\), and \((1, 3)\). There's an easy way and a hard way...

Solution:

Use Green's Theorem (the easy way):

With \(P = \sqrt{1 + x^3}\) and \(Q = 2xy\):

\[\oint_C P \, dx + Q \, dy = \iint_R \left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right) dA\]

Step 1: Compute the partial derivatives.

\[\frac{\partial Q}{\partial x} = 2y, \quad \frac{\partial P}{\partial y} = 0\]

Step 2: Set up the double integral.

Region: \(0 \le x \le 1\), \(0 \le y \le 3x\).

\[\iint_R 2y \, dA = \int_0^1 \int_0^{3x} 2y \, dy \, dx\]

Step 3: Evaluate.

\[= \int_0^1 y^2 \Big|_0^{3x} dx = \int_0^1 9x^2 \, dx = 3x^3 \Big|_0^1 = \boxed{3}\]

Problem 3: Conservative Vector Fields and FTOLI

For \(\mathbf{F} = \langle e^y, xe^y + e^z, ye^z \rangle\):

  • Show that \(\mathbf{F}\) is conservative (without constructing a potential function).
  • Find a potential function for \(\mathbf{F}\).
  • Use the potential function to evaluate \(\displaystyle\int_C \mathbf{F} \cdot d\mathbf{r}\) where \(C\) is the line segment from \((0, 2, 0)\) to \((4, 0, 3)\).

Solution:

Part (a): Show F is conservative

A vector field is conservative if \(\text{curl } \mathbf{F} = \mathbf{0}\).

\[\text{curl } \mathbf{F} = \begin{vmatrix} \mathbf{i} & \mathbf{j} & \mathbf{k} \\ \frac{\partial}{\partial x} & \frac{\partial}{\partial y} & \frac{\partial}{\partial z} \\ e^y & xe^y + e^z & ye^z \end{vmatrix}\]

\[= \mathbf{i}(e^z - e^z) - \mathbf{j}(0 - 0) + \mathbf{k}(e^y - e^y) = \langle 0, 0, 0 \rangle\]

Since \(\text{curl } \mathbf{F} = \mathbf{0}\) for all \((x, y, z) \in \mathbb{R}^3\), \(\mathbf{F}\) is conservative.

Part (b): Find a potential function

Step 1: From \(f_x = e^y\):

\[f = xe^y + C(y, z)\]

Step 2: Take \(f_y\) and compare:

\[f_y = xe^y + C_y = xe^y + e^z\]

So \(C_y = e^z\), which means \(C = ye^z + C(z)\).

Thus \(f = xe^y + ye^z + C(z)\).

Step 3: Take \(f_z\) and compare:

\[f_z = ye^z + C'(z) = ye^z\]

So \(C'(z) = 0\), meaning \(C(z) = \text{constant}\).

\[\boxed{f(x, y, z) = xe^y + ye^z}\]

Part (c): Evaluate the line integral using FTOLI

By the Fundamental Theorem of Line Integrals:

\[\int_C \mathbf{F} \cdot d\mathbf{r} = f(B) - f(A) = f(4, 0, 3) - f(0, 2, 0)\]

\[= (4e^0 + 0 \cdot e^3) - (0 \cdot e^2 + 2e^0)\]

\[= (4 + 0) - (0 + 2) = \boxed{2}\]
