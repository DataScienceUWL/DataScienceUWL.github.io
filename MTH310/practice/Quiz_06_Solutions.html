Problem 1: Optimization by Eliminating a Variable (Section 14.7)

A cardboard box without a lid is to have a volume of 32,000 cm³. Find the dimensions that minimize the amount of cardboard. Use the methods of Section 14.7, that is, start by eliminating a variable in the objective function.

Solution:

Setup:

Minimize: \(S = xy + 2xz + 2yz\) (bottom + 2 side faces + 2 front/back faces)

Subject to: \(xyz = 32{,}000\), where \(x, y, z > 0\)

Step 1: Eliminate \(z\) using the constraint.

\[z = \frac{32{,}000}{xy}\]

\[S = xy + 2x \cdot \frac{32{,}000}{xy} + 2y \cdot \frac{32{,}000}{xy} = xy + \frac{64{,}000}{y} + \frac{64{,}000}{x}\]

Step 2: Find critical points by setting partial derivatives to zero.

\[S_x = y - \frac{64{,}000}{x^2} = 0 \implies y = \frac{64{,}000}{x^2}\]

\[S_y = x - \frac{64{,}000}{y^2} = 0 \implies x = \frac{64{,}000}{y^2}\]

Step 3: Solve the system.

Substitute \(y = \frac{64{,}000}{x^2}\) into the second equation:

\[x - \frac{64{,}000}{\left(\frac{64{,}000}{x^2}\right)^2} = 0\]

\[x - \frac{x^4}{64{,}000} = 0\]

\[x\left(1 - \frac{x^3}{64{,}000}\right) = 0\]

Since \(x > 0\): \(x^3 = 64{,}000 \implies x = 40\)

Step 4: Find \(y\) and \(z\).

\[y = \frac{64{,}000}{40^2} = \frac{64{,}000}{1{,}600} = 40\]

\[z = \frac{32{,}000}{xy} = \frac{32{,}000}{40 \cdot 40} = 20\]

Final Answer:

\[\boxed{x = 40 \text{ cm}, \quad y = 40 \text{ cm}, \quad z = 20 \text{ cm}}\]

Note: The physical nature of the problem ensures a minimum exists, and it must occur at a critical point. (Alternatively, verify using the second derivative test.)

Problem 2: Optimization Using Lagrange Multipliers

A cardboard box without a lid is to have a volume of 32,000 cm³. Find the dimensions that minimize the amount of cardboard. Use Lagrange multipliers.

Solution:

Setup:

Minimize: \(f(x, y, z) = xy + 2xz + 2yz\)

Subject to: \(g(x, y, z) = xyz = 32{,}000\)

Step 1: Apply \(\nabla f = \lambda \nabla g\).

\[f_x = \lambda g_x: \quad y + 2z = \lambda yz \quad \text{...(1)}\]

\[f_y = \lambda g_y: \quad x + 2z = \lambda xz \quad \text{...(2)}\]

\[f_z = \lambda g_z: \quad 2x + 2y = \lambda xy \quad \text{...(3)}\]

\[g = k: \quad xyz = 32{,}000 \quad \text{...(4)}\]

Step 2: Multiply equations to eliminate \(\lambda\).

From (1): \(xy + 2xz = \lambda xyz\)

From (2): \(xy + 2yz = \lambda xyz\)

Setting these equal: \(xy + 2xz = xy + 2yz\)

\[2xz = 2yz \implies x = y \quad (\text{since } z > 0)\]

From (2): \(xy + 2yz = \lambda xyz\)

From (3): \(2xz + 2yz = \lambda xyz\)

Setting these equal: \(xy + 2yz = 2xz + 2yz\)

\[xy = 2xz \implies y = 2z \quad (\text{since } x > 0)\]

Step 3: Use \(x = y = 2z\) in the constraint.

\[(2z)(2z)(z) = 32{,}000\]

\[4z^3 = 32{,}000\]

\[z^3 = 8{,}000 \implies z = 20\]

Then: \(x = 2(20) = 40\) and \(y = 2(20) = 40\)

Final Answer:

\[\boxed{x = 40 \text{ cm}, \quad y = 40 \text{ cm}, \quad z = 20 \text{ cm}}\]
