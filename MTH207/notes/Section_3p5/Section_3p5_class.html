3.5  Implicit Differentiation

MTH 207 Calculus I — Differentiation Rules

A Curve With No Function

Every derivative so far started from $\displaystyle y = \text{something in } x$.

Your turn

For the circle $\displaystyle x^{2}+y^{2}=25$: solve for $\displaystyle y$, then differentiate. Use the upper half. Then try the same thing on $\displaystyle x^{3}+y^{3}=6xy$.

the circle — solve, choose, then differentiate

$\displaystyle x^{2}+y^{2} = 25$the equation you were given
$\displaystyle y^{2} = 25-x^{2}$isolate $\displaystyle y^{2}$
$\displaystyle y = \pm\sqrt{25-x^{2}}$stop here. That $\displaystyle \pm$ is two different functions
$\displaystyle y = +\sqrt{25-x^{2}} = \left(25-x^{2}\right)^{1/2}$choose the upper half, because the prompt said so
$\displaystyle y' = \tfrac12\left(25-x^{2}\right)^{-1/2}\cdot\left(-2x\right)$now, and only now, the Chain Rule
$\displaystyle y' = \frac{-x}{\sqrt{25-x^{2}}}$tidy

You made a choice, and you may not have noticed. Solving produced two functions and you had to pick one. Pick the other and you get the lower half, with its own derivative

$$y = -\sqrt{25-x^{2}} \qquad\Longrightarrow\qquad y' = \frac{+x}{\sqrt{25-x^{2}}}$$

Above the same $\displaystyle x$ the two slopes are opposites, which no formula in $\displaystyle x$ alone could produce. A function gives one $\displaystyle y$ per $\displaystyle x$; a circle gives two. That is why it had to be solved before it could be differentiated.

Show: now the second one — a wall

$\displaystyle x^{3}+y^{3}=6xy$ cannot be solved for $\displaystyle y$ at all. Not hard: impossible. Yet it has a tangent line nearly everywhere.

A curve can have a slope everywhere without being a function. We need a method that never solves for $\displaystyle y$ — and it needs nothing new, only the Chain Rule.

Differentiate Both Sides

$\displaystyle y$ is still a function of $\displaystyle x$ — the equation just does not hand you the formula. Differentiate both sides anyway.

My turn

The circle, all the way through, twice — once with a name put in and once straight through.

with the name put in

$\displaystyle x^{2}+y^{2} = 25$the original equation
$\displaystyle x^{2}+\left(f(x)\right)^{2} = 25$name it $\displaystyle f$ and put it in
$\displaystyle \frac{d}{dx}\left[\,x^{2}+\left(f(x)\right)^{2}\,\right] = \frac{d}{dx}\left[\,25\,\right]$differentiate both sides
$\displaystyle 2x + 2f(x)\,f'(x) = 0$second term is a composite — Chain Rule
$\displaystyle 2f(x)\,f'(x) = -2x$gather
$\displaystyle f'(x) = -\frac{x}{f(x)}$divide
$\displaystyle \frac{dy}{dx} = -\frac{x}{y}$put the name back

and again, with no name at all

$\displaystyle x^{2}+y^{2} = 25$the same equation
$\displaystyle 2x + 2y\,\frac{dy}{dx} = 0$differentiate — $\displaystyle y^{2}$ carries a $\displaystyle \frac{dy}{dx}$
$\displaystyle 2y\,\frac{dy}{dx} = -2x$gather
$\displaystyle \frac{dy}{dx} = -\frac{x}{y}$divide

Same derivation, line for line. $\displaystyle f$ was $\displaystyle y$ all along. From here on we write the short one.

Show: Check it against the hard way
$$y = \sqrt{25-x^{2}} \qquad\Longrightarrow\qquad y' = \frac{-x}{\sqrt{25-x^{2}}} = -\frac{x}{y}$$

Same answer — and this one is good on the whole circle.

Two moves, every time. Differentiate both sides, then solve for $\displaystyle \frac{dy}{dx}$. It is always linear in $\displaystyle \frac{dy}{dx}$, so the second move is only algebra.

Every $y$ Carries a $\frac{dy}{dx}$

Get this one move automatic before solving anything.

My turn

Three at the board, same question each time. The first and last are done twice — with $\displaystyle y$ written as $\displaystyle f(x)$, then the short way.

If $\displaystyle y$ is an implicit function of $\displaystyle x$, what is
$$\frac{d}{dx}\,y^{3}\,?$$
Show: both ways — the same line
$$\frac{d}{dx}\left(f(x)\right)^{3} = 3\left(f(x)\right)^{2}\cdot f'(x)$$
$$\frac{d}{dx}\,y^{3} = 3y^{2}\,\frac{dy}{dx}$$
If $\displaystyle y$ is an implicit function of $\displaystyle x$, what is
$$\frac{d}{dx}\,\sin y\,?$$
Show: same shape, sine outside
$$\frac{d}{dx}\,\sin y = \cos y\,\frac{dy}{dx}$$
If $\displaystyle y$ is an implicit function of $\displaystyle x$, what is
$$\frac{d}{dx}\,\left(xy\right)\,?$$
Show: a product — only one term gets the factor
$$\frac{d}{dx}\left(x\,f(x)\right) = f(x) + x\,f'(x)$$
$$\frac{d}{dx}\left(xy\right) = y + x\,\frac{dy}{dx}$$
Your turn

Same question each time: if $\displaystyle y$ is an implicit function of $\displaystyle x$, what is the derivative? Do not solve anything — just differentiate.

$$\text{(a)}\;\; \frac{d}{dx}\,y^{5} \qquad \text{(b)}\;\; \frac{d}{dx}\,e^{y} \qquad \text{(c)}\;\; \frac{d}{dx}\,x^{2}y \qquad \text{(d)}\;\; \frac{d}{dx}\,\cos\!\left(xy\right)$$
Show: (a) and (b), the two plain ones
$$\frac{d}{dx}\,y^{5} = 5y^{4}\,\frac{dy}{dx} \qquad\qquad \frac{d}{dx}\,e^{y} = e^{y}\,\frac{dy}{dx}$$
Show: (c), a product
$$\frac{d}{dx}\,x^{2}y = 2xy + x^{2}\,\frac{dy}{dx}$$
Show: (d), chain outside and product inside
$$\frac{d}{dx}\,\cos\!\left(xy\right) = -\sin\!\left(xy\right)\cdot\left(y + x\,\frac{dy}{dx}\right)$$

A $\displaystyle y$ in the term means a $\displaystyle \frac{dy}{dx}$ in its derivative. Drop it and the method collapses — silently, because what is left still looks like an answer.

Now You: Solve for $\frac{dy}{dx}$

My turn

One all the way through first, with a $\displaystyle y$ inside a trig function.

differentiate, gather, factor, divide

$\displaystyle y\cos x = x^{2}+y^{2}$the given equation
$\displaystyle \frac{d}{dx}\left[\,y\cos x\,\right] = \frac{d}{dx}\left[\,x^{2}+y^{2}\,\right]$apply $\displaystyle \frac{d}{dx}$ to both sides
$\displaystyle \frac{d}{dx}\left[\,y\,\right]\cos x + y\,\frac{d}{dx}\left[\,\cos x\,\right] = \frac{d}{dx}\left[\,x^{2}\,\right] + \frac{d}{dx}\left[\,y^{2}\,\right]$the left is a product — write the Product Rule out before computing anything
$\displaystyle \frac{dy}{dx}\cos x + y\left(-\sin x\right) = 2x + 2y\,\frac{dy}{dx}$now each piece: $\displaystyle \frac{d}{dx}y = \frac{dy}{dx}$, and $\displaystyle y^{2}$ carries one too
$\displaystyle \frac{dy}{dx}\cos x - 2y\,\frac{dy}{dx} = 2x + y\sin x$gather
$\displaystyle \frac{dy}{dx}\left(\cos x - 2y\right) = 2x + y\sin x$factor
$\displaystyle \frac{dy}{dx} = \frac{2x + y\sin x}{\cos x - 2y}$divide
Your turn

Your turn. Find $\displaystyle \frac{dy}{dx}$.

$$\text{(a)}\;\; x^{3}+y^{3}=6 \qquad\qquad \text{(b)}\;\; x^{2}y + y^{3} = 10$$
Show: (a)

$\displaystyle 3x^{2}+3y^{2}\frac{dy}{dx}=0$, so $\displaystyle \frac{dy}{dx} = -\frac{x^{2}}{y^{2}}$.

Show: (b)

$\displaystyle 2xy + x^{2}\frac{dy}{dx} + 3y^{2}\frac{dy}{dx} = 0$, so $\displaystyle \frac{dy}{dx}\left(x^{2}+3y^{2}\right) = -2xy$ and $\displaystyle \frac{dy}{dx} = \frac{-2xy}{x^{2}+3y^{2}}$.

Always the same three steps: gather, factor, divide.

A Curve Has Two Sides

My turn

Find the tangent line to $\displaystyle x^{2}+y^{2}=25$ at $\displaystyle (3,4)$, and then the tangent line at $\displaystyle (3,-4)$.

first, the slope formula — thirty seconds

$\displaystyle x^{2}+y^{2} = 25$the circle
$\displaystyle 2x + 2y\,\frac{dy}{dx} = 0$differentiate both sides; $\displaystyle y^{2}$ carries a $\displaystyle \frac{dy}{dx}$
$\displaystyle \frac{dy}{dx} = -\frac{x}{y}$gather and divide

one slope formula, two answers

$\displaystyle \frac{dy}{dx} = -\frac{x}{y}$from the circle — it needs $\displaystyle y$, not just $\displaystyle x$
$\displaystyle m = -\frac{3}{4}$at $\displaystyle (3,4)$
$\displaystyle y - 4 = -\tfrac34\left(x - 3\right)$$\displaystyle x_0=3$, $\displaystyle y_0=4$
$\displaystyle m = -\frac{3}{-4} = +\frac{3}{4}$at $\displaystyle (3,-4)$ — same $\displaystyle x$, opposite slope
$\displaystyle y + 4 = \tfrac34\left(x - 3\right)$$\displaystyle x_0=3$, $\displaystyle y_0=-4$

A $\displaystyle y$ in the slope formula is not an unfinished answer. Two points sit above $\displaystyle x=3$ with different slopes — no formula in $\displaystyle x$ alone could be right.

Your turn

What happens at the point $\displaystyle (5,0)$?

Show: undefined, and that is the answer

$\displaystyle \frac{dy}{dx} = -\frac{5}{0}$ is undefined. The tangent is vertical: the line $\displaystyle x = 5$. Undefined is the correct report, not a mistake.

When $x$ and $y$ Are Tangled

Same two moves, on equations where $\displaystyle x$ and $\displaystyle y$ sit inside each other.

My turn

$\displaystyle x\sin y + y\sin x = 1$. Two products, each with a trig function of the other variable.

differentiate, gather, factor, divide

$\displaystyle x\sin y + y\sin x = 1$the given equation
$\displaystyle \frac{d}{dx}\left[\,x\sin y\,\right] + \frac{d}{dx}\left[\,y\sin x\,\right] = \frac{d}{dx}\left[\,1\,\right]$apply $\displaystyle \frac{d}{dx}$ to both sides
$\displaystyle \frac{d}{dx}\left[\,x\,\right]\sin y + x\,\frac{d}{dx}\left[\,\sin y\,\right] + \frac{d}{dx}\left[\,y\,\right]\sin x + y\,\frac{d}{dx}\left[\,\sin x\,\right] = 0$two products — write both Product Rules out first
$\displaystyle \sin y + x\cos y\,\frac{dy}{dx} + \frac{dy}{dx}\sin x + y\cos x = 0$now each piece
$\displaystyle x\cos y\,\frac{dy}{dx} + \sin x\,\frac{dy}{dx} = -\sin y - y\cos x$gather
$\displaystyle \frac{dy}{dx}\left(x\cos y + \sin x\right) = -\sin y - y\cos x$factor
$\displaystyle \frac{dy}{dx} = \frac{-\sin y - y\cos x}{x\cos y + \sin x}$divide
Your turn

Find $\displaystyle \frac{dy}{dx}$ for $\displaystyle \;e^{y}\cos x = 1 + \sin\!\left(xy\right)$.

differentiate, gather, factor, divide

$\displaystyle e^{y}\cos x = 1 + \sin\!\left(xy\right)$the given equation
$\displaystyle \frac{d}{dx}\left[\,e^{y}\cos x\,\right] = \frac{d}{dx}\left[\,1 + \sin\!\left(xy\right)\,\right]$apply $\displaystyle \frac{d}{dx}$ to both sides
$\displaystyle \frac{d}{dx}\left[\,e^{y}\,\right]\cos x + e^{y}\,\frac{d}{dx}\left[\,\cos x\,\right] = \cos\!\left(xy\right)\cdot\frac{d}{dx}\left[\,xy\,\right]$left is a product, right is a chain — write both out before computing anything
$\displaystyle e^{y}\,\frac{dy}{dx}\cos x + e^{y}\left(-\sin x\right) = \cos\!\left(xy\right)\left(y + x\,\frac{dy}{dx}\right)$now each piece: $\displaystyle e^{y}$ carries a $\displaystyle \frac{dy}{dx}$, and the inside $\displaystyle xy$ is itself a product
$\displaystyle e^{y}\cos x\,\frac{dy}{dx} - x\cos\!\left(xy\right)\frac{dy}{dx} = e^{y}\sin x + y\cos\!\left(xy\right)$gather — every $\displaystyle \frac{dy}{dx}$ to the left, everything else to the right
$\displaystyle \frac{dy}{dx}\left(e^{y}\cos x - x\cos\!\left(xy\right)\right) = e^{y}\sin x + y\cos\!\left(xy\right)$factor
$\displaystyle \frac{dy}{dx} = \frac{e^{y}\sin x + y\cos\!\left(xy\right)}{e^{y}\cos x - x\cos\!\left(xy\right)}$divide

Long does not mean different. Differentiate both sides, then gather, factor, divide.

What You Should Be Able to Do

  • Differentiate without solving for $\displaystyle y$ — every $\displaystyle y$ carries a $\displaystyle \frac{dy}{dx}$.
  • Gather, factor, divide to get $\displaystyle \frac{dy}{dx}$ by itself.
  • Read a $\displaystyle y$ in the answer as correct, not unfinished.
  • Find a tangent line on an implicit curve, and read an undefined slope as a vertical tangent.

No new rule here — the Chain Rule on a function you cannot write down, plus three lines of algebra.
