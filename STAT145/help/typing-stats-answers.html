Typing statistics answers in MyOpenMath

STAT 145 · a quick guide for written-response problems

Some STAT 145 problems ask you to write your answer — an explanation, an interpretation, or a set of hypotheses. This page shows how to type the math so it looks right.

The one rule: wrap math in backticks

MyOpenMath turns anything between backticks (`, the key above Tab) into typeset math. Everything outside backticks stays as ordinary text.

Type this:

The null hypothesis should be `H_0: p = 0.25`.

and it shows as:

The null hypothesis should be `H_0: p = 0.25`.

You can mix words and math freely — write a normal sentence and drop math in backticks wherever you need a symbol.

Writing hypotheses correctly

Two things graders look for:

  • Hypotheses are always about a population parameter — `p` or `mu` — never about a sample statistic like `hat(p)` or `bar(x)`.
  • The null hypothesis uses the claimed value being tested, not a number from your data.

Worked examples

Two-sided (testing whether a proportion differs from 0.5):
type `H_0: p = 0.5` and `H_A: p != 0.5` → `H_0: p = 0.5`, `H_A: p != 0.5`

One-sided (testing whether a mean is greater than 100):
type `H_0: mu = 100` and `H_A: mu > 100` → `H_0: mu = 100`, `H_A: mu > 100`

Common mistakes

✗ `H_0: hat(p) = 0.46` — uses the sample statistic and a data value.
✓ `H_0: p = 0.5` — parameter and the claimed value.

If your problem has an equation button

A few problems give you a rich text box with an Add New Math button (a summation symbol in the toolbar). Click it to insert a math field where you can build an equation visually — no backticks needed there. For every other problem, use the backtick method above.
Note: MyOpenMath uses ASCIIMath, not LaTeX. So \hat{p} will not work — type `hat(p)` instead. When in doubt, you can always describe the math in words (“p-hat”, “the population proportion”); either is fine for a written explanation.
